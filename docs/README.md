# Документация timeofthestars-backend-v2

Бэкенд и админ-панель хоккейной лиги «TIME OF THE STARS».
FastAPI + PostgreSQL + серверная админка на Jinja2. Работает в бою:
**https://api.timeofthestars.ru**

## С чего начать

| Если вы | Читайте |

| впервые видите проект | [Архитектура](architecture.md) → [Модель данных](data-model.md) |
| пишете фронтенд | [../API_FRONTEND.md](../API_FRONTEND.md) и [../API_FRONTEND_TIMELINE.md](../API_FRONTEND_TIMELINE.md) — это контракт для фронта, отдельно от бэкендовой документации |
