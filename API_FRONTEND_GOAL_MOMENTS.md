# Моменты голов игрока — для карточки игрока

Документ самодостаточный: чтобы сделать блок «моменты» в профиле игрока, читать другие файлы
не нужно. Общие правила работы с API (пагинация, ошибки, отсутствие слэшей на конце) — в
[API_FRONTEND.md](API_FRONTEND.md), таймлайн матча — в
[API_FRONTEND_TIMELINE.md](API_FRONTEND_TIMELINE.md).

База: `https://api.timeofthestars.ru`

---

## 1. Зачем это

У каждого гола в хронологии матча можно указать момент в видеозаписи. Раньше эти таймкоды
были видны только внутри протокола конкретного матча — чтобы собрать «все голы игрока с
видео», пришлось бы выкачать все его матчи и отфильтровать события вручную.

Теперь есть готовая ручка: один запрос отдаёт голы игрока со ссылкой на нужную секунду.

---

## 2. Запрос

```
GET /api/v1/players/{id}/goal-moments
```

Публичная, токен не нужен. Ответ — **массив без обёртки**, пагинации нет.

### Коды ответа

| Код | Когда |
|---|---|
| `200` | всегда, когда игрок существует — в том числе `[]`, если моментов нет |
| `404` | игрока с таким id нет: `{"detail": "Игрок не найден"}` |

Пустой массив — нормальная ситуация, а не ошибка: см. раздел 5.

## 3. Поля

| Поле | Тип | Смысл |
|---|---|---|
| `event_id` | `number` | id события в хронологии матча — годится как React-key |
| `game_id` | `number` | матч; ссылка на страницу матча строится отсюда |
| `type` | `"goal" \| "shootout_goal"` | обычный гол или гол в серии буллитов |
| `period` | `number \| null` | 1–3, `4` — овертайм, **`null` у буллита** |
| `time_seconds` | `number` | игровое время гола от начала матча (960 = 16:00) |
| `video_seconds` | `number` | момент в записи матча, секунды от начала видео |
| `video_url` | `string` | ссылка на запись матча целиком |
| `video_at_url` | `string` | **готовая ссылка на момент** — то, что вешаем на кнопку |
| `date` | `string` | дата матча, `YYYY-MM-DD` |
| `competition_id` | `number` | соревнование |
| `competition_name` | `string` | его название — отдельный запрос не нужен |
| `team` | `Team` | команда, за которую забит гол |
| `opponent` | `Team` | соперник |
| `score_for` | `number \| null` | итоговый счёт **своей** команды |
| `score_against` | `number \| null` | итоговый счёт соперника |
| `assist1` | `Player \| null` | первая голевая передача |
| `assist2` | `Player \| null` | вторая |

`video_seconds`, `video_url` и `video_at_url` **никогда не `null`** — записи без них в выдачу
не попадают, так что проверять их не нужно.

`score_for` / `score_against` — уже со стороны команды игрока: разбираться, хозяин он или
гость, не требуется. `null` бывает только у матча без проставленного счёта.

### Типы

```ts
export interface Team {
  id: number; name: string; slug: string;
  city: string | null; logo_url: string | null;
}

export interface Player {
  id: number; full_name: string; birth_date: string | null;
  position: "вратарь" | "защитник" | "нападающий" | null;
  grip: string | null; photo_url: string | null;
}

export interface PlayerGoalMoment {
  event_id: number;
  game_id: number;
  type: "goal" | "shootout_goal";
  period: number | null;          // null у буллита
  time_seconds: number;           // игровое время гола
  video_seconds: number;          // момент в записи
  video_url: string;              // запись матча целиком
  video_at_url: string;           // готовая ссылка на момент
  date: string;                   // YYYY-MM-DD
  competition_id: number;
  competition_name: string;
  team: Team;                     // за кого забит гол
  opponent: Team;
  score_for: number | null;       // счёт со стороны команды игрока
  score_against: number | null;
  assist1: Player | null;
  assist2: Player | null;
}
```

## 4. Как показывать

Порядок готовый: **свежие матчи сверху**, внутри матча — по игровому времени. Сортировать
заново не нужно.

```tsx
const moments = await get<PlayerGoalMoment[]>(`/api/v1/players/${id}/goal-moments`);

{moments.map(m => (
  <a key={m.event_id} href={m.video_at_url} target="_blank" rel="noopener">
    <span>{formatDate(m.date)}</span>
    <span>против {m.opponent.name}</span>
    <span>{clock(m.time_seconds)}</span>
    {m.type === "shootout_goal" && <span className="badge">буллит</span>}
    {m.assist1 && <span>с передачи {m.assist1.full_name}</span>}
  </a>
))}
```

Игровое время выводится как `MM:SS` **сквозным счётом**, без часов: 2505 секунд — это 41:45
третьего периода, а не «41 минута матча плюс час».

```ts
// 960 -> "16:00", 2505 -> "41:45"
export const clock = (s: number) =>
  `${String(Math.floor(s / 60)).padStart(2, "0")}:${String(s % 60).padStart(2, "0")}`;
```

**Не форматируйте так `video_seconds`** — это позиция в записи, она легко переваливает за час
(4095 секунд = 1:08:15), и `MM:SS` покажет бессмысленные «68:15». Для видео есть готовая
ссылка, собирать ничего не надо.

## 5. Данных пока мало — это ожидаемо

Таймкоды проставляются вручную в админке при вводе протокола, и заполнены они далеко не
везде. На 15.09.2026:

- **8 голов с моментом** из 124 забитых, все в одном матче (18.08, Ярославич — Зубр);
- моменты есть **у 7 игроков**, у одного из них — два;
- у 13 матчей из 18 привязана запись, но таймкоды у голов не расставлены.

Поэтому у подавляющего большинства игроков ручка вернёт `[]`. **Блок «моменты» должен
аккуратно исчезать**, а не показывать пустую рамку или спиннер. Со временем моментов станет
больше — фронт менять не придётся.

Игроки, у которых сейчас есть что показать: 96, 98, 533, 527 (два момента), 524, 94, 514.

## 6. Подводные камни

1. **Ссылку собирать не нужно.** Берите `video_at_url` как есть. Формат `?t=` со стороны
   сервера уже учитывает часы (`1h8m15s`), а самодельная сборка вида `68m15s` VK разбирает
   ненадёжно. Функция `videoAt()` из общего контракта остаётся только для таймлайна матча.
2. **Буллит — тоже гол.** `type: "shootout_goal"`, и у него `period: null`. Если верстаете
   «1 период / 2 период», предусмотрите ветку без периода.
3. **Голевые передачи момента не создают.** Если игрок только ассистировал, у него в списке
   ничего не появится — момент принадлежит забившему. Но `assist1` / `assist2` в записи есть,
   чтобы подписать «с передачи такого-то».
4. **`assist1` может быть `null` у реального гола** — в бумажном протоколе передачу могли не
   записать, либо игрока позже удалили из базы. Не считайте передачу обязательной.
5. **Гол без таймкода в список не попадает.** Число моментов не равно числу голов игрока:
   голы целиком считаются в `GET /api/v1/players/{id}/stats`.
6. **`logo_url` и `photo_url` относительные** (`/media/…`) — склеивайте с базовым URL API.
7. **Без слэша на конце.** `/goal-moments`, не `/goal-moments/` — иначе `307`.

---

## 7. Что рядом

| Нужно | Ручка |
|---|---|
| карточка игрока | `GET /api/v1/players/{id}` |
| его статистика (карьера, по соревнованиям и командам) | `GET /api/v1/players/{id}/stats` |
| матчи, где игрок заявлен в протоколе | `GET /api/v1/players/{id}/games` |
| полный протокол матча с таймлайном | `GET /api/v1/games/{id}` |

Ручки «моменты по матчу» или «все моменты лиги» нет — если понадобится лента хайлайтов,
скажите, добавим.
